
# Proyecto: Análisis de Emisiones de CO₂ en Colombia

##  Descripción
Este proyecto analiza la evolución de las emisiones de dióxido de carbono (CO₂) en Colombia desde 1990 hasta 2025, utilizando datos de la plataforma Our World in Data. Incluye limpieza de datos, visualizaciones, un modelo de regresión lineal e interpretación de resultados.

##  Integrantes del grupo
- Integrante 1: Limpieza y preparación de datos
- Integrante 2: Visualización y análisis exploratorio
- Integrante 3: Modelo de regresión lineal e interpretación final

##  Estructura del repositorio
- `datos_limpios_colombia.csv` — Datos filtrados y listos para análisis
- `annual-co2-emissions-per-country.csv` — Datos originales descargados
- `1_Limpieza_Datos.ipynb` — Cuaderno de limpieza de datos
- `2_Visualizacion_Analisis.ipynb` — Gráficos y análisis exploratorio
- `3_Regresion_Lineal.ipynb` — Modelo predictivo y conclusiones

##  Fuente de los datos
Hannah Ritchie and Max Roser (2020) — "CO₂ emissions". Published online at OurWorldinData.org.
